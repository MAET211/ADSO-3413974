## Contexto

El SRS deja explícitamente fuera de alcance ciertas funcionalidades para esta primera versión (v1.0), dejándolas planteadas como posibles versiones futuras.

## Contenido

| Ítem | Estado | Nota |
|---|---|---|
| Facturación electrónica DIAN | Fuera de alcance v1.0 | Podría requerirse si el negocio crece o cambia su régimen tributario. |
| Aplicación móvil | Fuera de alcance v1.0 | El sistema actual solo funciona desde navegador web (RNF-005). |
| Integración con pasarelas de pago | Fuera de alcance v1.0 | El SRS no detalla método de pago electrónico; se asume pago en efectivo por el contexto del negocio. |
| Rol "Supervisor" | Parcialmente definido | El SRS lo describe como "opcional, si crece el negocio"; sus permisos exactos deberán refinarse cuando se implemente. |
| Procedimiento formal de backups | Pendiente de definir | El SRS solo indica que es responsabilidad del administrador, sin frecuencia ni herramienta específica. |
