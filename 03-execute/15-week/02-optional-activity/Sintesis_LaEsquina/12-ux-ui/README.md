## Contexto

El SRS incluye un requerimiento no funcional de usabilidad (RNF-003) que orienta directamente los lineamientos de interfaz.

## Contenido

### Lineamientos de usabilidad
- La interfaz debe estar completamente en español, evitando tecnicismos.
- Un cajero sin experiencia previa debe poder registrar una venta en menos de 5 pasos, después de una breve capacitación.
- Priorizar formularios simples y directos, con búsqueda de productos por nombre o código visible desde la pantalla principal de ventas (RF-009).
- El diseño debe funcionar correctamente en pantallas de escritorio y portátil, desde cualquier navegador moderno (RNF-005).

### Pantallas mínimas sugeridas (derivadas de los casos de uso)
- Pantalla de venta (búsqueda de producto, carrito, total, confirmación).
- Pantalla de inventario (listado con indicador visual de stock bajo).
- Pantalla de catálogo de productos (alta/edición/baja).
- Pantalla de reportes (selección de periodo y resultados).

## Referencias
- SRS v1.0, RNF-003, RNF-005, RF-009 y sección 6.
