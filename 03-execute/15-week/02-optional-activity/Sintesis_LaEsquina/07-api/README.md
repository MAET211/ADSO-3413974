## Contexto

El SRS describe una aplicación web monolítica en Laravel con vistas renderizadas del lado del servidor (Blade Templates), sin mención de una API REST, endpoints, ni contratos de integración con terceros.

## Contenido

No aplica una definición de API en esta versión del proyecto, dado que no hay frontend desacoplado ni consumidores externos previstos. Esta carpeta se deja como `🔴 Pendiente` intencionalmente: si en una futura iteración se decide separar frontend y backend, o exponer datos a una futura aplicación móvil (mencionada como fuera de alcance en el SRS), este sería el lugar para documentar los contratos correspondientes.
