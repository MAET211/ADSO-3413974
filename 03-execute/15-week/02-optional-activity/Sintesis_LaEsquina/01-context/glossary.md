## Contexto

Términos de negocio usados de manera consistente en toda la documentación del proyecto.

## Contenido

| Término | Definición |
|---|---|
| Administrador | Rol con acceso completo al sistema: ventas, inventario, reportes, usuarios y configuración. Ejercido por Don Carlos. |
| Cajero | Rol operativo que registra ventas y consulta el catálogo y el stock disponible. |
| Supervisor | Rol intermedio opcional, pensado para cuando el negocio crezca; puede consultar reportes y ajustar inventario, pero no eliminar registros. |
| Catálogo de productos | Listado de productos disponibles para la venta, con nombre, precio, categoría, stock y proveedor asociado. |
| Stock mínimo | Cantidad mínima configurada por producto; al llegar a ese umbral el sistema notifica al administrador. |
| Cierre de caja | Resumen diario generado por el sistema: total vendido, número de transacciones y efectivo recibido. |
| Recibo | Comprobante generado automáticamente al confirmar una venta. |
| RF / RNF | Abreviaturas de Requerimiento Funcional y Requerimiento No Funcional respectivamente. |
