## Contexto

El SRS describe explícitamente una aplicación web monolítica desarrollada en Laravel con vistas Blade renderizadas del lado del servidor (sección 3.1 y 3.3), pensada para un negocio de barrio con recursos limitados y sin necesidad de escalar a cientos de usuarios simultáneos (sección 7, restricciones).

## Contenido

No aplica una arquitectura de microservicios para este proyecto. Dividir el sistema en servicios independientes agregaría complejidad de despliegue, comunicación entre servicios e infraestructura que no se justifica para el alcance y los recursos del cliente descritos en el SRS. Esta carpeta se deja documentada como `⚫ No aplica` para dejar constancia de la decisión y su justificación, en caso de que en el futuro el negocio crezca y se reconsidere.
