## Contexto

Esta sección define las reglas mínimas para mantener ordenada la documentación del proyecto Supermercado La Esquina a lo largo del proceso de formación.

## Contenido

### Naming
- Archivos en `kebab-case.md`.
- Carpetas raíz con prefijo numérico `NN-nombre`, sin crear carpetas nuevas sin justificación.

### Estructura mínima de cada documento
Todo archivo `.md` de este repositorio inicia con encabezado de Estado, Última actualización, Autor/Equipo y Fuente, seguido de las secciones Contexto, Contenido y Referencias.

### Estados
| Estado | Uso |
|---|---|
| 🔴 Pendiente | No hay información suficiente en el SRS |
| 🟡 En progreso | Información parcial o inferida |
| 🟢 Estable | Información completa y respaldada por el SRS |
| ⚫ No aplica | La sección no corresponde a este proyecto |

### Alcance de esta síntesis
Este repositorio se generó a partir de un único documento fuente (el SRS v1.0). No sustituye el levantamiento de información adicional que se haga más adelante en el proceso de formación (arquitectura detallada, pruebas, DevOps avanzado, etc.); simplemente organiza y desarrolla lo que el SRS ya establece.
